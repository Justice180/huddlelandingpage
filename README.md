This is a landing page for Huddle, a platform that helps create and build communities where users can engage in genuine discussions. The landing page features a modern design with a call to action for users to register and join the community. It includes a navigation bar, a main content section, and social media icons.

Features
Navigation Bar: Includes the Huddle brand name.

Responsive Layout: The page is responsive and adjusts to different screen sizes.

Mockup Illustration: A visual representation of the platform.

Call to Action: A "Register" button to prompt users to join.

Social Media Icons: Links to Facebook, Twitter, and Instagram.

Installation
Clone the repository:

git clone https://github.com/your-username/huddle-landing-page.git
Navigate into the project folder:

cd huddle-landing-page
Open index.html in your browser to view the landing page.
